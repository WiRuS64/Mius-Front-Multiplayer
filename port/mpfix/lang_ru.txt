# Mius-Front Multiplayer: Russian texts. Shown when the game runs in Russian (root\engine.txt says loc_rus) or
# when MP_LANG=ru is set; with English the mod's own texts are shown.
#
# Pairs: the English line exactly as the mod draws it, the Russian line under it, an empty line between pairs.
# In the English line %s %u %d %.1f %02d ... stand for values (a name, a number). In the Russian line %1 %2 ...
# put them back, numbered in the English order; %% is a percent sign. A value is translated as well when it is
# an entry of its own here ("the host", "Germany", "deployment" ...). An English line starting with ~ is a piece
# that is replaced inside values nothing else matched.
# The first entry that matches wins: keep longer patterns above shorter ones that would also match.
# Saved as UTF-8; build_mpfix.py turns it into text_ru.h (Windows-1251).
